# contracts

JSON Schemas versionados (`evaluate-transaction.v1`, `rule-set.v1` etc.), exemplos e testes de contrato. Artefato `br.com.motorfraude:contracts` (com `test-jar`), consumido por receiver, rule-management, engine e load-generator.

Depende do pom pai (`motor-fraude-parent`). `./mvnw verify` roda os testes; `./mvnw install` instala em `~/.m2`.
Visão geral: https://github.com/luizavramos/motor-fraude
